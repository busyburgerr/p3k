# Site starter

Каркас статического сайта на Vue 3 + TSX и Vite. Без роутера, без стейт-менеджера,
без UI-кита: единственная рантайм-зависимость — `vue`.

## Начать

```bash
npx degit <владелец>/<репозиторий>/starter my-site
cd my-site
npm install
npm run dev
```

Локально, без git-хостинга, работает и просто `cp -r starter my-site`.

## Что внутри

| Файл | Зачем |
|---|---|
| `src/site.ts` | Единственное место с контентом: маршруты, навигация, данные секций |
| `src/styles.css` | Дизайн-токены (CSS-переменные) и утилитарные классы |
| `src/components/Section.tsx` | Каркас секции: обёртки, заголовок, подключение к скроллу |
| `src/composables/useReveal.ts` | Появление секций при скролле |
| `src/composables/useHashRoute.ts` | Маршруты и якоря на хэше |
| `src/composables/useTheme.ts` | Тёмная/светлая тема |
| `src/composables/useCopy.ts` | Копирование в буфер с откликом |

Остальные компоненты — примеры. Их надо заменить своими.

## Три правила, на которых всё держится

**Секции регистрируются сами.** `provideReveal()` в `App.tsx` создаёт один
`IntersectionObserver` на страницу, а `Section` подписывает на него свой корень.
Нигде нет списка id секций, поэтому ему нечем разъехаться с разметкой. Добавили
секцию — она подключилась.

**Скрытие включается только когда наблюдатель запущен.** Правило `opacity: 0`
живёт под селектором `[data-reveal-ready] [data-reveal]`, а атрибут ставится на
`<html>` из JS. Нет JS или нет `IntersectionObserver` — контент виден. Никогда не
пишите безусловный `opacity: 0` для появляющихся блоков.

**Оформление идёт от токенов.** Цвета берутся только из переменных `--bg`,
`--ink`, `--muted`, `--line`, `--accent`, `--panel`, `--ok`. Светлая тема — это
переопределение тех же переменных в `[data-theme='light']`, поэтому ни один
компонент про тему не знает.

## Добавить секцию

```tsx
import Section from './Section'

export default defineComponent({
  name: 'MySection',
  setup: () => () => (
    <Section id="my" title="Заголовок" kicker="ПОДПИСЬ">
      {{
        default: ({ shown }: { shown?: string }) => (
          <div class="cols">
            <div class="cell" data-reveal data-shown={shown}>…</div>
          </div>
        ),
      }}
    </Section>
  ),
})
```

`id` нужен, только если на секцию ведёт якорь. `data-reveal` ставится на те
элементы, которые должны проявляться, — `shown` приходит из слота.

## Маршруты

Форма ссылки: `#/<маршрут>#<якорь>`, у корневой страницы — просто `#<якорь>`.
Список маршрутов задаётся в `src/site.ts`; пустой массив превращает сайт в
обычный одностраничник. Ссылки стройте через `href()`, а не строками: якорь
доезжает и при переходе между страницами, где браузер сам бы не справился.

```ts
href('')                 // '#'
href('', 'pricing')      // '#pricing'
href('docs')             // '#/docs'
href('docs', 'install')  // '#/docs#install'
```

## Известные ограничения

Оформление живёт в инлайновых `style`-строках. Для своего сайта это удобно
(правка видна рядом с разметкой), но переопределить такой стиль снаружи нельзя —
если каркас понадобится как npm-пакет, стили придётся выносить в CSS.

Composables читают `window` в `setup`, поэтому SSR (Nuxt) из коробки не заведётся.
